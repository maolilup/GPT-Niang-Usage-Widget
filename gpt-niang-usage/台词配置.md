# 自定义台词与表情

Windows 右键角色 →「编辑台词与表情」，可以直接编辑完整 JSON。也可以选择「打开台词配置文件」，用自己的编辑器修改。

默认文件为 `%LOCALAPPDATA%\GPTNiangUsage\state\dialogue.json`。如安装时选择了其他数据目录，文件放在 `installation.json` 的 `dataDir` 下。首次正常运行会生成完整配置，带入原来的自定义语录、权重和表情；以后升级保留此文件。旧 `quotes.json` 保留，Windows 后续编辑使用 `dialogue.json`。

保存后约 1～2 秒自动载入，下一句使用新配置。正在显示的台词和表情会保持到本句结束。右键「重新载入台词」可以立即检查配置。

```json
{
  "version": 1,
  "daily": [
    { "text": "今天心情不错，想吃点甜的。", "expression": "happy", "weight": 1 }
  ],
  "headpat": [
    { "text": "唔……再摸一下嘛。", "expression": "sleepy", "weight": 1 }
  ],
  "lowQuota": [
    { "text": "剩这点额度，得省着聊了。", "expression": "worried", "level": "low", "weight": 1 },
    { "text": "最后这点额度，咱们留给要紧的事。", "expression": "worried", "level": "critical", "weight": 1 },
    { "text": "等额度恢复，咱们接着聊。", "expression": "worried", "level": "empty", "weight": 1 }
  ]
}
```

这是一个精简示例。把整个文件替换成示例后，日常只会抽取示例中的那一句。需要保留现有台词时，直接在现有数组里增删或修改条目。可直接复制的示例文件是 [dialogue.example.json](assets/dialogue.example.json)。

| 字段 | 含义 |
| --- | --- |
| `daily` | 点击和定时对话使用的日常台词，至少保留一条 |
| `headpat` | 摸头回应；设为 `[]` 可关闭摸头台词 |
| `lowQuota` | 低额度回应；设为 `[]` 可关闭低额度台词 |
| `text` | 台词，1～200 字 |
| `expression` | 下表中的表情名，必须填写 |
| `weight` | 抽取权重，可省略，默认 1；须大于 0 且不超过 1000 |
| `level` | 仅低额度条目使用：`low` 为剩余高于 5% 且不足 20%，`critical` 为高于 0% 且不超过 5%，`empty` 为 0% |

同一组内的台词应唯一；低额度组以 `level` 和 `text` 共同区分。相同文字可以在不同组使用不同表情。多于一条时避免连续重复，抽取概率按权重计算。

| 表情名 | 效果 | 表情名 | 效果 |
| --- | --- | --- | --- |
| `neutral` | 默认 | `happy` | 开心 |
| `shy` | 害羞 | `thinking` | 思考 |
| `surprised` | 惊讶 | `sleepy` | 困倦 |
| `worried` | 担忧 | `wave` | 挥手 |
| `cheer` | 双拳欢呼 | `pout` | 抱臂鼓脸 |
| `comfort` | 合掌安慰 | `wink` | 俏皮眨眼 |
| `smug` | 得意点赞 | `curious` | 好奇歪头 |
| `focused` | 认真指点 | `laugh` | 开怀大笑 |
| `teary` | 感动泪目 | `mischievous` | 捂嘴偷笑 |
| `determined` | 坚定握拳 | `apologetic` | 歉意低头 |
| `bored` | 托腮等待 | `dizzy` | 晕乎乎 |
| `heart` | 双手比心 | | |

想按台词切换表情时，请在「表情与动作」中选择「自动表情」。手动固定表情仍优先。低额度提醒的触发时机与原有定时对话开关保持一致。

JSON 写到一半、文件暂时被编辑器占用或表情名无效时，挂件继续使用本次运行中上次有效的配置；重载入口的提示和内置编辑器会显示错误。首次启动就遇到无效配置时使用内置台词，并保留原文件供修复。修好后保存即可重新载入。

内置编辑器保存或恢复全部内置台词时，会将之前的文件备份为 `dialogue.json.bak`。恢复操作影响日常、摸头和低额度三组；外部编辑器的备份规则由编辑器自行决定。

这个功能目前接入 Windows 挂件。macOS 仍沿用原有语录配置。
