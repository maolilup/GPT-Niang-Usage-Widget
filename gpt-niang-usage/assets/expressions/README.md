# 表情与动作素材

当前 Windows 挂件提供 **23 种表情与动作**：原始立绘、第一批 10 款差分和本批 12 款差分。每种表情有至少 10 句逐句配对的内置台词，共 254 句日常对话与 12 句摸头专属回应。

右键角色 →「表情与动作」可手动选择，默认「自动表情」会按当前台词与常态切换。手动固定的表情会保留；低额度提醒仍使用担忧表情，进入手动对话后使用该句配套表情。

本批素材使用内置 **ImageGen**，以项目原始立绘为编辑目标，并参考现有抱臂素材的服装与手部画法。保持透明背景、正方形画布、头部位置、角色比例和胸口裁切线。完整提示词见 [prompts-v2.json](prompts-v2.json)，来源与形象权利说明见 [素材说明](../生成说明.md)。

第一批素材：开心、害羞、思考、惊讶、困倦、担忧、挥手、双拳欢呼、抱臂鼓脸、合掌安慰。
