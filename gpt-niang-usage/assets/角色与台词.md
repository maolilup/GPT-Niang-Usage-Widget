# 角色与台词

这份人设参考上游 1.3.1 的 33 句语录，供本 fork 编写台词使用。它是本分支的创作约定。

她坐在屏幕边上，有点懒，爱面子，喜欢碎碎念。关心午饭、午休和下班，爱找舒服的角落。心情好时会开小玩笑，遇到难题愿意琢磨，被指出错误会有些难为情。摸头舒服时会想再来一下，也会惦记被揉乱的头发。

她知道自己是 AI，会关心额度，偶尔聊模型的糗事。日常也有自己的小心思：想吃点甜的，想晒太阳，想给工位添个靠垫。陪伴通过这些随口的反应表现出来。

## 写法

- 用“我”或省略主语，每句直接说一个意思，语气接近日常口语。
- **绝对禁止前面否定、后面肯定的句式。** 同样排除把两个分句摆成前后反转、辩解或对照的写法。整句重写，不能仅替换连接词。
- 每个梗放在合适的情境里，控制模型、token 和上班话题的密度。
- 关心说具体一点，感谢要有明确缘由。日常随机台词避开凭空夸进步、宣布代码成功、假装看过工作内容。
- 摸头回应围绕触碰、舒服、痒或头发；低额度台词围绕有效的剩余额度和等待重置。
- 表情跟随句子的情绪。台词无需讲解眨眼、握拳或比心动作。
- 内容检查在数量检查之前，逐句读出声，检查是否像一个人随口说话。

## 代表台词

- 日常：“这个角落坐着还挺舒服。” → 常态
- 得意：“你挑挂件的眼光挺好嘛。” → 得意
- 摸鱼：“嘘，摸鱼算我一份。” → 眨眼
- 摸头：“唔……再摸一下嘛。” → 困倦
- 低额度：“剩这点额度，得省着聊了。” → 担忧
- 用完：“等额度恢复，咱们接着聊。” → 担忧
